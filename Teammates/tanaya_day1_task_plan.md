# Tanaya — Short Day 1 Task Plan

## Main responsibility

Tanaya is providing **light research and QA support** for PastPort India. Day 1 is only for helping the team organize information and identify basic risks. **She does not need to create PPT slides or work on presentation design on Day 1.**

## Day 1 tasks

1. Understand the SIH26195 problem and the PastPort India concept.
2. Learn the basic product flow:

```text
Search Taj Mahal → Read history → Explore 3D → View in AR → Optional VR
```

3. Understand the difference between:
   - **3D:** rotate and zoom the model on a normal screen;
   - **AR:** view the model through the phone camera in the real world; and
   - **VR:** enter a virtual environment on a compatible device.
4. Help Manmath or Khushi check whether basic Taj Mahal facts and images have source links.
5. Prepare a small checklist of things that should be tested later, such as:
   - app opens on a phone;
   - buttons are readable;
   - AR has a fallback;
   - VR has a fallback;
   - images load; and
   - historical information has a source.
6. Ask the technical team for any unclear terms and write simple explanations for later use.

## What she should not do on Day 1

Tanaya should **not create PPT slides, edit the PPT file, design presentation pages, or spend a long time preparing visuals** on Day 1.

She should not change:

```text
AR files
VR files
3D/model files
frontend files owned by Priyansh or Shreyas
backend or database files
package.json or lock files
.env files
```

She should not edit Siddhant’s AR branch or Shreyas’s frontend branch. If she finds a problem, she should record it in a note or GitHub issue instead of changing the code herself.
